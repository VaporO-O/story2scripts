## 结论范围

以上验证证明了已定义规则和工作流的行为，不证明真实模型的事件抽取准确率或创作质量。没有运行真实模型的文学质量评测。引用存在、覆盖索引齐全也不能单独证明语义蕴含或抽取完整；这些仍需要作者核对和语义审校。

独立规则测试：`python -m pytest tests/test_logic_engine.py tests/test_plot_revision.py -q`。

离线评测：`python -m story2script.evaluation run --dataset evals/datasets/v1/dev.json --dataset evals/datasets/v1/holdout.json --baseline evals/baselines/demo-v1.json --output-dir evals/reports --report-prefix logic-regression --fail-on-regression`。
